# שירים משלכם

הרדיו מנגן מנגינות ילדים קלאסיות (נחלת הכלל) שנוצרות בזמן אמת.
כדי להוסיף שירים אמיתיים מהמשפחה:

1. העתיקו קבצי `.mp3` (או `.m4a` / `.ogg`) לתיקייה הזו.
2. צרו כאן קובץ `songs.json` ברשימה הזו:

```json
[
  { "title": "השיר של דני", "emoji": "🎵", "file": "dani.mp3" },
  { "title": "שיר ערש",      "emoji": "🌙", "file": "lullaby.mp3" }
]
```

השירים יופיעו ברדיו יחד עם המנגינות המובנות.

אפשר גם בלי זה: בתוך הרדיו יש כפתור "➕ שיר מהמכשיר" שמנגן קבצים
ישירות מהטלפון (לאותו משחק בלבד, בלי לשמור).
