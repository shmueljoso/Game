# לוגואים של יצרני הרכב

האמבלם שעל כל רכב מצויר מקורי (מגן עם האות הראשונה).
אם תרצו להחליף אותו בלוגו האמיתי של היצרן:

1. שמרו קובץ PNG שקוף (רצוי ריבועי, 128x128 ומעלה) בתיקייה הזו.
2. שם הקובץ צריך להיות מזהה הרכב מתוך `js/cars.js`, למשל:
   `toyota.png`, `mazda.png`, `kia.png`, `hyundai.png`, `skoda.png`,
   `geely.png`, `nissan.png`, `byd.png`, `ford.png`, `jeep.png`,
   `tesla.png`, `racer.png`, `bus.png`, `truck.png`, `monster.png`

3. הוסיפו את המזהה לקובץ `logos.json` שבתיקייה, למשל:

```json
["toyota", "mazda", "jeep"]
```

הלוגו ייטען אוטומטית ויוצג על תג הרכב. בלי זה נשארת האות.

הערה: הלוגואים של היצרנים הם סימני מסחר רשומים. השימוש כאן הוא פרטי
ומשפחתי, ולכן הקבצים לא נכללים בקוד - מי שרוצה מוסיף אותם בעצמו.
